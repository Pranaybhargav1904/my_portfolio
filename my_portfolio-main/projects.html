Smart Resume Analyzer

An AI-driven platform that scores resumes against job descriptions to surface skill gaps and produce an actionable match score. The frontend is built in React.js; the backend runs on Java Spring Boot with Supabase for data persistence and AWS S3 for document storage. AI analysis is powered by the OpenAI API, providing deep language-level recommendations for resume optimization.

AI-Powered Expense Tracker

A full-stack expense tracking platform where users record, organize, and monitor spending through a responsive Next.js 15 / React 19 / TypeScript frontend. The backend uses Supabase for PostgreSQL data persistence and authentication. Integrated Groq AI (Llama 3.3 70B) to power a natural-language financial query interface — users can ask questions about their spending and receive personalized insights through an LLM-driven analytics layer.
