AI-Powered Expense Tracker

An expense-tracking application where users can record, organize, and monitor their spending. It also offers an AI assistant that answers questions and gives personalized financial insights. Built with modern technologies including Next.js 15, React 19, TypeScript, and Tailwind CSS for a responsive frontend. Smart Resume Analyzer

It analyzes a user's resume and job description to highlight skill gaps and suggest improvements. It also gives a match score showing how well the resume aligns with the job description. Built with React.js for the frontend and Java Spring Boot for the backend, with Supabase for data storage and AWS S3 for file storage. The AI analysis is powered by OpenAI API or Ollama to provide intelligent insights and recommendations for resume optimization.

React.js Java (Spring Boot) Supabase OpenAI API / Ollama AWS S3 (File Storage)
Resume Analysis Skill Gap Identification Match Score Calculation
